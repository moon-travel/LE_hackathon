# Implementation Plan: face-auth-onsen-entry (顔認証温泉入場・決済システム)

## Overview

design.md(AWS構成 / A案: Amazon Rekognition採用)に基づき、CDK(TypeScript)によるIaC構築からLambda各関数、Next.jsフロントエンドまでを一貫したTypeScript実装として計画する。

- 要件13(Template_Codecの自前実装)はdesign.md 0節の割り切りに従いスコープ外とする。特徴量のエンコード/デコード相当の処理はRekognitionのCollection内部管理に委譲され、自前実装・検証の対象が存在しないため、本タスクリストにも対応タスクを設けない。
- design.mdには「Correctness Properties」の独立節は存在しないが、決済の冪等性・残高の上下限・保管期限算定などは要件本文に数値的な不変条件が明記されているため、これらに限定してproperty-based testサブタスクを組み込む。各プロパティにはProperty番号と検証対象の要件条項を付す。
- 実装言語はTypeScript(CDK / Lambda(Node.js 20.x) / Next.js)に統一する。design.mdが具体的な言語を指定しているため、擬似コードの実装言語選択は不要。
